About this tool

An academic, defensive security project. Analysts paste the results of malware analysis they have already performed (notes, strings/readelf output, sandbox reports) and the page generates a detection and incident-response framework for ISPs: indicators of compromise, MITRE ATT&CK mapping, YARA/Suricata detection rules and mitigation steps.

  • Runs entirely in your browser. Nothing you paste or select is uploaded or stored anywhere.
  • No accounts, passwords or personal data are requested.
  • Hosts and distributes no malware, and executable files are rejected. The exploit strings in the code are detection signatures used to recognise known attacks.

Source code: github.com/victoriaodemakin/gpon-framework
